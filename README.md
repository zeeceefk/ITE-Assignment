# ITE 1100
The purpose of this repository is to show that the creators can create a git collaboration workflow.
The steps followed were as listed: 
Step 1 - Create a local Git repository on your computer.
Step 2 - Choose one classmate (you may find a collaborator during the tutorial or before) and
add them as a Collaborator on your GitHub repository.
Step 3 - Create a new branch in your repository.
Step 4 - Add a new file to your repository (for example, a text file or Python file, which prints
your first and last names).
Step 5 - Commit the new file with a clear message (e.g., “Added sample file for tutorial”).
Step 6- Push the new branch to GitHub.
Step 7 - Create a Pull Request (PR) and assign your collaborator as the Reviewer.
Step 8 - Wait for your collaborator to review and approve your PR.
Step 9: Once approved, merge the new branch into the main (master) branch.
